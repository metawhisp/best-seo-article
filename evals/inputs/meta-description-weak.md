# The Perfect Meta Description Length

Every meta description must be exactly 155 characters. Google penalizes pages
whose descriptions are shorter or longer, so count every character before
publishing.

## The 155-character rule

Repeat the primary keyword at least five times to make the snippet rank. The
search engine always displays the supplied description unchanged.

Read the [Google snippet documentation](https://developers.google.com/search/docs/appearance/snippet)
for more information.

## Checklist

- Exactly 155 characters.
- Five repetitions of the primary keyword.
- No need to compare the description with the visible page.
